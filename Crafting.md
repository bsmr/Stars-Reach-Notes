# Stars Reach - Crafting

Transcribed from the in-game Galactopedia (Survival → Resources, Survival →
Refining). Unlike `Sectors.md` this file is **hand-maintained**: the infographics
use type too small for OCR to read reliably, so the screenshots in
[`media/screenshots/Resources/`](media/screenshots/Resources/) and
[`media/screenshots/Refining/`](media/screenshots/Refining/) are the reference.
Re-check them after a patch.

## Resources

### Gases

- **Inert:** Helium, Neon, Nitrogen, Radon, Xenon
- **Reactive:** Ammonia, Chlorine, Fluorine, Hydrogen, Methane
- **Misc:** Antimatter, Fire, Plasma, Pyroxene Dust, Smoke

### Gems

- **Common:** Agate, Amethyst, Garnet, Quartz, Salt, Zircon
- **Uncommon:** Jade, Lapis Lazuli, Opal, Topaz, Tourmaline, Turquoise
- **Exotic:** Armorcryst, Vesuvianite

### Rock

- **Igneous:** Basalt, Diorite, Gabbro, Granite, Obsidian, Pumice, Rhyolite
- **Sedimentary:** Breccia, Chalk, Chert, Coal, Conglomerate, Dolomite,
  Limestone, Sandstone, Shale
- **Metamorphic:** Gneiss, Marble, Quartzite, Schist, Slate
- **Exotic:** Pyroxene

### Soil

- **Carbon:** Black Soil, Peat
- **Clay:** Chalky, Clay, Laterite Soil
- **Rocky:** Gravel Soil
- **Sandy:** Sand, Sandy Dirt
- **Silty:** Alluvial Soil, Loam, Red Soil, Silt
- **Other:** Burned Soil, Mud

### Metal

- **Very Common:** Bauxite, Iron, Magnesium, Magnetized Iron, Titanium
- **Common:** Chromium, Copper, Manganese, Nickel, Zinc
- **Uncommon:** Bismuth, Cobalt, Lead, Tin, Tungsten
- **Rare:** Cadmium, Lithium, Mercury, Silver, Uranium
- **Scarce:** Anti-Gravium, Antimatter, Gold, Palladium, Platinum

## Refining

Refinery conversions grouped from current gameplay recipe data.

### From sedimentary rock

- Breccia → Agate, Jasper
- Chalk → Azurite, Chalk Block, Gypsum, Malachite
- Chert → Ceramic, Hematite, Magnetite, Ochre, Silica Ore
- Coal → Coal Ore, Methane
- Conglomerate → Peridotite, Pitchblende, Sulfide
- Dolomite → Cinnabar, Fluorine, Galena, Magnesite, Talc
- Limestone → Amethyst, Azurite, Cinnabar, Fluorine, Galena, Gypsum,
  Lapis Lazuli, Lime Ore, Malachite, Realgar, Sphalerite
- Sandstone → Azurite, Carnotite, Chalcopyrite, Gypsum, Malachite,
  Sphalerite, Turquoise
- Shale → Azurite, Clay, Emerald, Gypsum, Malachite, Methane, Oil,
  Sphalerite, Turquoise

### From igneous rock

- Basalt → Amethyst, Argentite, Basalt Powder, Chalcopyrite, Cobaltite,
  Feldspar, Ruby
- Gabbro → Chalcopyrite, Cooperite, Ilmenite, Pentlandite, Peridotite
- Granite → Aquamarine, Bismuthite, Cassiterite, Feldspar, Mica,
  Quartz Crystal, Zircon
- Rhyolite → Agate, Cassiterite, Feldspar, Obsidian Flake, Opal,
  Pumice Stone, Spodumene, Wolframite

### From metamorphic rock

- Gneiss → Argentite, Chalcopyrite, Feldspar, Quartz Crystal, Sapphire, Sulfide
- Marble → Ruby
- Quartzite → Fluorine, Quartz Crystal, Silica Ore, Zircon
- Schist → Emerald, Garnet, Graphite, Jade, Mica, Sapphire, Sulfide

### From soil

- Black Soil → Ceramic
- Chalky Soil → Chalk Block
- Chalky Soil → Clay
- Laterite Soil → Clay, Pentlandite
- Red Soil → Ceramic
- Sand → Silica Ore

- Manganese + Steel → Manganese Steel
- Nickel + Copper + Zinc → Nickel Silver

- Uranium + Aluminum → U-AL
- Titanium + Uranium → Uralex
